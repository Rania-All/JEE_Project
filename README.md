# JEE Project

## Description
Ce projet est une application Java EE qui vise à démontrer les fonctionnalités de base de Java Enterprise Edition. Il inclut des exemples d'utilisation de servlets, JSP et d'autres technologies Java EE.

## Fonctionnalités
- Authentification des utilisateurs
- Gestion des sessions
- Accès à une base de données
- Interface utilisateur avec JSP

## Prérequis
- JDK 11 ou supérieur
- Maven 3.6 ou supérieur
- Serveur d'applications (par exemple, Apache Tomcat)

## Installation
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Rania-All/JEE_Project.git
   ```
2. Naviguez dans le répertoire du projet :
   ```bash
   cd JEE_Project
   ```
3. Compilez le projet avec Maven :
   ```bash
   mvn clean install
   ```

## Exécution
Déployez le fichier WAR généré dans le répertoire `target` sur votre serveur d'applications.
